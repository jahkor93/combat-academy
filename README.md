# Combat & Survival Academy v3

Gamaken companion update.

## New in v3
- purple main theme with green secondary accents
- Gamaken companion card on the home screen
- 6 evolution stages linked to academy rank
- 3 moods: Calm, Inspired, Resting
- companion XP progress bar
- updated visual style using the approved Gamaken concept art
- existing training history preserved by keeping the original localStorage key

## Companion evolution mapping
- Cadet → Pond Initiate
- Recruit → Temple Novice
- Operator → Dojo Disciple
- Fighter → Warrior Monk
- Senior Fighter → Shrine Guardian
- Academy Graduate → Sage of the Academy
